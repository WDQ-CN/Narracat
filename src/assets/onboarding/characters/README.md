# 首次介绍 · 角色画廊素材

第三幕「让笔下的人活过来」用 CircularGallery 展示一组角色图，增强代入感。

把角色图放进**本目录**即可被自动加载（`character-gallery.ts` 用 `import.meta.glob` 读取），无需改代码。

## 规格

| 项 | 要求 |
|---|---|
| 格式 | `.webp` 优先（`.png` / `.jpg` 也支持） |
| 比例 | **竖图**，约 7:9（卡片是竖向，角色立绘/半身最贴） |
| 数量 | 6–12 张最佳 |
| 文件名 | 会被转成卡片下方的标签（如 `少年剑客.webp` → 「少年剑客」），用中文命名即可 |

未放图时，第三幕画廊位置显示一行引导提示；放入图片后自动渲染为可旋转的角色画廊。
