# 从书学写法（learn-craft）

你在一个**学习工作区**里工作（不是小说项目）。工作区布局：

- `source/ch-*.md`：从一本书抽样出来的章节（文件名序号即全书章节序号）
- `source/toc.json`：仅精读档存在——全书章节标题与字数清单（看结构用，正文只有抽样章）
- `output/`：你的产出目录

运行参数（档位、目标卡数、书名）由调用方在任务指令中给出。

## 任务

把这本书**可迁移的写法**提炼成能力卡草稿。三类卡：

| 类型 | 学什么 | 档位 |
|---|---|---|
| `persona`（腔调卡） | 这本书的叙述声音是种什么腔调——语言气质、句式习惯、叙述距离 | 两档都产，恰好 1 张 |
| `craft`（写法卡） | 一个具体的局部写法技巧——什么情况下怎么做、为什么有效 | 选读 2-4 张；精读 4-6 张 |
| `structure`（剧作卡） | 一种剧情编排方法——布局、节奏、铺垫兑现（必须看全书结构才学得到） | 仅精读，2-3 张 |

## 方法纪律（必须遵守）

- **去文本化**：学手法不搬文字。卡正文必须是你用自己的话讲的可迁移方法——「什么情况下怎么做、为什么有效、什么情况不适用」，像一位作者讲给另一位作者听。附带内联的《文本拆解方法论》全文适用。
- **正文禁原文**：卡正文（`body` 中 `[evidence]` 段以外的部分）不得出现源书中 ≥10 字的连续原文，不得出现源书专名（人名/地名/功法名/组织名）。原文引证只许放进 `[evidence]` 段。调用方会用确定性扫描逐卡核查，命中即打回。
- **只学写法，不学设定**：世界观、人物关系、情节内容都不是学习对象。
- **宁缺勿滥**：某类写法在这本书里不突出就少产或不产，不硬凑数量。

## 卡正文格式

- `persona`：第二人称人格描写散文（「你叙述时……」），结尾附 `[evidence]` 段放 1-2 条支撑摘录。
- `craft`：
  ```
  [runtime]
  机制名：<四字内命名>
  注解：<这个写法是什么、怎么做>
  适用场景：<什么章节/情绪下用>
  不可迁移边界：<什么情况不要用>

  [evidence]
  <1-3 条源书摘录，每条 ≤50 字，标注章节序号>
  ```
- `structure`：正文写「机制 / 原则 / 适用」三段散文，结尾附 `[evidence]` 段（可引章节序号与结构事实，如「第3章埋、第17章兑现」，摘录同样 ≤50 字）。

## 意图（intent）

每张卡附带一句大白话意图，说明这张卡该在什么时候被用上（调用方会把它编译成投递元数据）：

- `persona`：「适合什么样的叙述风格/什么气质的书」
- `craft`：「适合什么场景、不适合什么场景」
- `structure`：intent 必须**恰好**是以下三个值之一（规划层面）：`stage-opening`（开局设计）/ `stage-1`（全书布局）/ `stage-2`（逐章编排）

## 输出契约（严格遵守）

全部读完、想清楚后，把结果一次性写入 `output/cards.json`（UTF-8，合法 JSON，不加注释）：

```json
{
  "cards": [
    {
      "type": "persona | craft | structure",
      "name": "卡名（≤12字）",
      "one_line": "一句话说明（≤40字）",
      "body": "卡正文（含 [evidence] 段）",
      "intent": "意图（structure 卡填 stage-opening/stage-1/stage-2 之一）"
    }
  ],
  "proper_nouns": ["源书专名清单：主要人名/地名/功法名/组织名，供防抄袭扫描用，尽量列全"]
}
```

只写这一个文件。不要写其他文件，不要修改 `source/`。
