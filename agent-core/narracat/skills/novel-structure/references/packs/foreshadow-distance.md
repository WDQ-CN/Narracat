# 伏笔布距与长线中继

## 机制

伏笔能否兑现，根本取决于读者记忆存活多久。小伏笔埋下、读者带着悬念往下读——如果十几章内没有兑现，悬念自然消散，兑现那一刻什么爽感都没有，这叫死伏笔。跨度越长，记忆消耗越大，必须用外力续命。

真人网文的解法是三层布距：小伏笔（个位到十几章）在弧内快兑，提供即时因果闭环和阅读黏性；中伏笔（几十章）卷内收束，承载身份/关系/阴谋的核心反转；只有贯穿全书的核心设定才能跨卷百章以上。层级不是建议，是记忆规律强制的约束。长线大伏笔要活过几十到几百章，必须靠中继 clue 续命——阶段性的小揭示、反复出现的道具、配角无意间的一句话——每隔一段就唤醒读者对这条线的期待，让悬念保持热度，而不是埋下后几百章静默无声等最后引爆。

## 原则

- 小伏笔 arc 内快兑（个位数到十几章）；中伏笔卷内收束；只有贯穿全书的核心设定才能跨卷。
- 真人样本中小伏笔集中于个位到十五章；明显超出此区间的小伏笔，若无显性中继即视为死伏笔风险，应降档或拆分。
- 长线伏笔（跨度超 80 章）必须规划中继 clue 节点：每隔 20-30 章至少一处阶段性小揭示/反复道具/配角侧证。
- 中继 clue 要推进悬念，不能只是重复设定——或部分揭晓、或与新情节产生摩擦、或道具在重要节点再度现身。
- 大伏笔（跨卷）无中继等于烂尾伏笔，无论最终兑现多精彩，读者早已忘记当初埋下了什么。

## 真人范例

> 真人范例① · 某书小/中/大三档清晰分层：小伏笔2章即收（即时人际误解），中伏笔10章时作者有意识插入中继、在关键节点兑现情感动机，长伏笔52至86章以具体物品（名牌、原谅卡）作锚点延长存活期。三层形成"即时嚼头—中距中继—长距震撼"结构，各档互不侵占，读者记忆始终有东西搭着往下走。

> 真人范例② · 某书长线靠道具接力：一件具体物品第4章植入，第66章以"碎玉"形式中继唤醒记忆，第78章揭示真身份完成闭环，从第4章埋入到第78章揭底读者不遗忘，因为道具三度现身且每次推进悬念（埋→裂变→揭底）。该书整体布距短伏2-3章/中伏10-20章/长伏接近百章，无断档。

> 真人范例③ · 88个可溯真人兑现样本：中位数15章，最短1章即兑，长线极端可达640、670、1500章。极长线均配有高频中继（反复出现的人物/地点/道具线索），小伏笔集中于个位到十五章，证明"快兑=基本盘"；凡偏离该区间的小伏笔，基本沦为死伏笔。

## 适用

架构师在阶段一建 foreshadowing_registry 时，为每条伏笔填写 `planted_chapter`（埋设章号）、`target_reveal`（兑现锚点，纯章号如"86"或卷级粗锚如"vol-03"，不写"第…章"）和 `type`（层级：major/medium/small），跨度由 target_reveal 减 planted_chapter 推算、架构师不另填距离字段；按三层布距核查层级与跨度是否匹配——小伏笔跨度超标立即降档或拆分。跨度超 80 章的长线，须在 foreshadowing_registry 中同步新增 type=medium/small 的中继条目（各有独立 planted_chapter/target_reveal、与主条目用 `theme_link` 关联），代表阶段性唤醒节点（部分揭晓/道具再现/配角侧证），不能只记录最终 target_reveal。

阶段二铺 `beats` 时同一条纪律延伸到随手带出的具体叙事元素（道具、生物、次要角色、线索）：一旦它在场景里制造了威胁或吊起了期待，就欠读者一次交代——要么当场收尾，让它在同一章的 `beats` 里有始有终；要么计划留到后面再用，就在 foreshadowing_registry 补一条 `type: small` 登记、本章 `foreshadowing_touch` 标 `plant`，把它接进这套布距节奏，不要让它平白登场又不声不响地消失。
