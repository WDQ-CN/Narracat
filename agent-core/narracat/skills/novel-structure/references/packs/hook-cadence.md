# 章末钩类型轮换与密度

## 机制

章末钩的本质是在一章结束的瞬间制造一个未完成态，逼读者翻到下一页。它是追读黏性的第一杠杆——一章读完如果情绪归零、赌注结清，读者就有了合上书的天然借口；一章读完还悬着一件事没了结，翻页几乎是本能。四类钩挂在不同的认知机制上：危机钩（danger）挂"人物会不会出事"的安全焦虑，悬念钩（suspense）挂"接下来会怎样"的信息缺口，情感钩（emotional）挂"这份情绪往哪里去"的共情牵挂，无钩（none）则主动松开这根弦、给读者一个喘息的着陆点。头部网文样本里约七成章带钩，其中悬念类约四成最常用、危机类约两成、情绪类近一成；约三成章无钩，属正常呼吸。题材要再校准一层：科幻末世这类强情节题材带钩率可高达八成五，现代言情则常不足六成——不是言情不需要钩，而是它更多把钩落在情绪层而非事件层。

但钩子密度只是下限，真正决定黏性的是类型是否轮换。固定用同一种收束节奏——章章都靠"突然出事"或章章都靠"留一句意味深长的话"——读者的神经会很快对这个套路脱敏，钩子还在，牵引力却漏光了。相邻章换一种钩，让安全焦虑、信息缺口、情绪牵挂交替上阵，读者始终被不同的绳子牵着，才是密度背后真正起作用的东西。

## 原则

- 每章都要显式决定 `end_hook` 挂哪类钩；无钩的缓冲章是刻意的松弛决策，不是忘了填。
- 相邻章尽量换类型，连排同型钩会钝化——三章都靠危机收尾，第三次的"出事"就不再让人紧张。
- 连续无钩是追读死区：约三成章无钩是常态，但成片无钩不是，读者会在没有牵引的段落里流失。
- arc 末章、卷末章倾向 danger 或 suspense 的强钩，把赌注顶到最高再翻页；紧随其后的余波章可以落 emotional 或 none，让读者喘一口。
- 六式收束手法各有归属的枚举，规划时按手法反查该填哪类钩：事件悬念（一件事悬而未决）→ suspense 或 danger（有安全威胁时）；对话戛然（一句台词砍在关键处）→ suspense；日常裂缝（平静里露出一道异常）→ suspense（弱钩）；情绪留白（把情绪悬置不收）→ emotional；行为回声（一个小动作余味不散）→ emotional；视角切换（末段切到另一视角制造信息差）→ suspense。

## 真人范例

> 真人范例① · 危机钩层层加压：某末世重生长篇，主角自以为囤物资瞒天过海，作者先用大段内心独白铺平静日常麻痹警惕；随后一记敲门声骤然破局，对方身份层层剥落——先谎称外卖，再露出多人围堵，接着亮逮捕令，最后直接亮枪，把危险一步步顶到顶点；同时用信息差点破主角最藏的秘密，逼她无路可退违心放人进门。章末落在这句妥协台词上，把接下来会怎样直接甩给下一章。

> 真人范例② · 反转钩一句翻盘：某现代言情长篇，把整场戏包装成契约谈判——一方先甩出条款全倾向自己的合同、摆出居高临下，另一方看完只淡淡说我同意，紧接着反问我可以有条件吗，用身份反转夺回主动权；作者刻意把真正的条件按住不表，先铺垫掏出高级证件的仪式动作，最后才用极短一句我要求结婚收尾，这要求完全出乎临时伴侣的框架，用反差极大的落点把整章博弈瞬间升级，吊读者看对方如何应对。

> 真人范例③ · 情绪留白跳时态：某言情长篇，整章是闺蜜间轻松八卦，主角一再强调对现任的绝对笃定；作者却在章末突然跳出当下时态，用"那时／后来"的对照句把镜头拉到多年后的主角，用"只剩缄默不语"暗示这段感情终以伤痛收场。不揭示具体发生了什么，只留一句意味深长的宿命伏笔，靠悬置感勾读者追问后来到底怎么了。

> 真人范例④ · 末段换视角制造信息差：某悬疑长篇，全章用插科打诨的日常对话把气氛压得轻松，随后场景切到雨夜一栋死过人的破败民宿，脱落的警戒线、床上的血渍把喜剧调子一步步拧成命案悬疑；末尾却不落在两位主角身上，反而突然切镜头给一个配角，让他毫无防备地摸黑翻窗潜进这栋凶宅取包——读者刚被提醒这里死过人，视角一换，信息差瞬间拉满，吊着人想看他会撞上什么。

## 适用

架构师在阶段二规划章级细纲、为每章填 `end_hook` 时用本包定类型与轮换：先按这一章在 arc 里的位置判断该挂强钩还是给缓冲（末章／卷末倾向 danger/suspense，余波章可 emotional/none），再对照相邻章已填的类型有意识地换一种，避免连排同型。`beats` 末条写钩子的事件层内容（末尾具体发生了什么、哪句话砍在哪里），`end_hook` 只声明这一钩属于哪个枚举，二者配合——事件层给素材、枚举给类型标签。缓冲章要克制：连续 3 章 `end_hook` 为 none 会触发提交告警，无钩缓冲段应控制在 1-2 章，用完立刻回到带钩节奏。
