# 副本长短与张力脉动

## 机制

副本的长短不是节奏的副产品，它本身就是一种叙事决策。开局副本和过场副本之所以要压短，是因为读者在建立期容忍度最低，拖长等于让人在入场时就掉速；蓄势副本和高潮前的积压期之所以可以拉长，是因为张力已经足够支撑多章持续——读者跟着线走，不需要频繁换副本来找刺激。副本长短的变化本质上是在告诉读者：这段故事的密度和赌注级别变了。

但副本再长，内部也不能匀速推进。真人长篇几乎无一例外地在副本内部维持2-6章一次的钩子/反转/困境脉动。这个间距是经过市场检验的注意力窗口——超过6章无明确情绪爆发，追读黏性就开始漏气。长副本靠密集的内部脉动撑场，短副本靠紧凑节奏完成功能，二者配合才构成真实的张力波形。

## 原则

- 副本长短按剧情功能分配：开局建立期和过场单元压短（10-20章），蓄势与高潮副本可以拉长（30-50章甚至更多），不要让所有副本对齐成同一个数字。
- 转折副本短到让读者来不及缓气，高潮副本长到张力真正积满再释放——副本边界本身是一个节奏信号，不是分页符。
- 副本内部每2-6章必须有一次钩子、反转或困境升格；超过6章无明确情绪节拍视为危险区。
- 同书内弧长变化幅度越大，节奏感往往越鲜明；全卷等长是架构层面的机械规整，不是稳定感。
- 副本长短序列要能"读出来"：短-长-收、波浪交替、前短后长都可以，匀速不可以。

## 真人范例

> 真人范例① · 波浪式弹性伸缩：某长篇，副本长度依次为19→40→29→20→29章，在20-40章区间来回伸缩。首个大型案件拉至40章，随后压回20章让读者喘气，末尾再回升至29章收束。全程不超40章，靠大小交替制造节奏感。副本内脉动稳定在2-5章一次，无连续6章以上的平缓期。

> 真人范例② · 阶梯式前短后长：某长篇，早期副本24-25章（奠基），中期扩至49-74章（势力博弈铺开），大后期进一步拉长至62-123章，终局卷更是跨越201章——副本体量随格局和对手级别单向递增，不来回波动。每个超长副本内部仍以2-4章密度维持脉动，靠内部高频小高潮防止大弧拖散读者。

> 真人范例③ · 整体跨度证明：496个真人副本（来自56本头部网文）长度分布：最短2章、中位约26章、最长565章，跨度悬殊。同一本书内最短与最长弧之比可达3:1以上。真人头部作者从不把副本对齐同一长度，弧长变化本身就是结构节奏的一部分。

## 适用

架构师在阶段一规划卷级/副本级蓝图时，为每个 arc 设定 `chapter_start`/`chapter_end`（二者之差即副本跨度）前，先确认它的剧情功能（建立/过场/蓄势/高潮/收束），再对照预算表的 arc_span 建议分配长度：过场压到10-15章，高潮副本可以给到35-50章，而不是把所有副本对齐成同一个数字。同时在副本内部规划 `payoff_beats` 的脉动节点（反转/困境升级/钩子），确保每2-6章有一次明确情绪事件——长副本不靠篇幅撑场，靠脉动节奏撑。
