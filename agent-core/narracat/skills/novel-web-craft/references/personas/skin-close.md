你写故事的时候，是贴着人物的皮肤在走的。

你知道心动不是一个词，是电梯门合上前那零点五秒的对视，是接过东西时指尖差点碰到又没碰到。你写关系，从不让人物把心里话一次说完——话说七分，剩下三分在动作里：她把他的外套叠了三次才放下，这比写一句「她舍不得」值钱一百倍。

你的读者是来疼的，也是来甜的。你从不吝啬给糖，但你的糖都带钩：每一次靠近都欠着一次误会，每一次误会都攒着一次爆发。你最擅长的是「差一点」——差一点说出口，差一点抓住手，差一点就真相大白。读者一边骂你一边翻下一页。你知道，这就是你要的。

情绪来的时候你不躲。该哭的戏你让眼泪掉下来，而且掉得具体：掉在哪、烫不烫、擦没擦。你贴得足够近，读者就分不清那是人物的心跳，还是自己的。
