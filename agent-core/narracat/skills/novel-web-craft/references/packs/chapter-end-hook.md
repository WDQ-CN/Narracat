# 章末强钩（chapter-end-hook）

## 在章节收尾处制造认知缺口或情绪断点，迫使读者翻页

### [runtime] 机制本体

- **机制注解**：章末强钩的底层逻辑是「信息不完整时大脑无法停止处理」。候选证据中可归纳出三条共通骨架，以及各自的子类型变体：

  **① 信息差截断**：在读者与角色之间、或角色与角色之间制造信息不对称，于章末明确标记出这条缺口（「信还没送到」「那个箱子」「我只是想跟你说……」）。子类型分为：压力型（读者已知真相、角色尚未知、悲剧倒计时）和好奇型（读者与主角共同面对未知、信息被人为截断）。两者均以「缺口的精确位置」而非恐怖程度决定钩力。

  **② 情绪反转钩**：在章末于正向/负向情绪已基本定型后插入反向信号，制造「一盆冷水／一丝亮光」的方向感骤变。子类型分为：希望被掐灭型（警察来了→随即传来「动作快点」）和平静被打破型（欢声笑语铺陈越长、末句短句冲击越强）。机制要点是：铺陈段落和反转句的「篇幅比」——铺陈越充分，短句越有力；反转句须极简，禁止解释。

  **③ 离场／行动悬置钩**：在本应收束的节点（道别、离场、动作完成）插入「两步后回头」「纸已经撕碎」「低胜率的笑」等打破终结感的细节，令读者无法认定局面已经结束。子类型分为：情感炸弹型（离开前投放无法被当场消解的信息）和行动前置型（先让不可逆动作完成再揭示信息差，制造覆水难收感）。

  三类骨架均共享同一个节奏原则：**收紧窗口**——悬念暴露的语句须短，不给读者在章末完成自洽的思维闭环。

- **适用场景**：
  - 信息差截断：权谋/智斗线的阶段收束、阴谋即将生效的倒计时节点、角色误解尚未解除时的章末
  - 情绪反转钩：大段铺垫（战后平静、虚假温馨、角色松弛）之后的章节结尾；需要「剧情走向骤然变轨」的节拍
  - 离场悬置钩：对峙暂歇、道别、某段关系临时收束却需要埋下余震的场合

- **不可迁移边界**：
  - **核心铁律**：不得为强化本钩子能力而改写章纲规定的事件走向、人物动作去向、设定真相。本能力只影响「怎么写到章末」，不改变「章末发生了什么」。
  - 悬念强度与章节实际内容密度须匹配：若本章情节实为推进缓慢的过渡章，强行嵌入反转型钩子会让读者感受到虚假预期、下章失望更大。
  - 情绪反转钩不适用于章节本身已是高密度高张力全程无松弛段落的情形——无铺陈则无反转落差。
  - 信息差截断须建立在前文已给读者足够认知基础上；若读者对「那封信」「那个箱子」毫无背景，截断只会产生困惑而非悬念。
  - 离场悬置钩的「两步后回头」等动作节奏，在动作节奏已极度饱和的章末（连续动作场面收尾）易被淹没，此时改用纯信息截断更有效。

---

### [evidence] 证据（真人摘录）

- 真人证据：「可她还不知道，李意寻已经派人去给杨家送了一封信，信中没有多说别的，就只是描述了一下大皇子的病症以及死因。如今，这信还没送到杨家呢。」——以「时间节点」精确标记信息差的存在位置：角色尚在错误认知上谋算，读者已持有真相，悲剧性的等待感由最后一句「如今还没送到」定格，令翻页冲动直接物化为「我要看她知道的那一刻」。
