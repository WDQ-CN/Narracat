# 紧张对话·言语博弈（tense-dialogue）

## 用台词的表面退让包裹核心不退——让对手在逻辑闭环或认知偏差中自行缴械

### [runtime] 机制本体

- **机制注解：**

  紧张对话的张力不来自声音大小，而来自**说话者之间的信息不对称与节奏控制**。候选覆盖三大子类型，有共通骨架也有各自的关键变量：

  **① 连环反问·逻辑闭环型**：说话者不直接给结论，而是依次抛出利益节点，每抛一点即停顿，引导听者主动推导，使结论由"被告知"变成"自行得出"，说服力远超陈述式施压。反问句式承担双重功能：语气制造压迫感 + 引导对方参与推理。

  **② 进—退—收三拍型**：一方质问施压（进），另一方反问防御（退/僵持），双方几乎同时觉察过激而各自软化（收）。有效性在于两人平行完成情绪降落，避免单方道歉的权力失衡，冲突因此不流于吵架，而成为双方心理距离缩短的契机。

  **③ 以退为进·示弱吸收型**：弱势一方承认对方的每一项指控，但在最后一步完成反转——承认卑微反而成为最有力的立场宣示（"我会走，但我还会再回来"）；或把谎言设计成符合对手认知偏见的形状，让对手以己度人自行相信。核心是：退的每一步都是另一种进，妥协中保留不可撼动的核心诉求。

  **共通骨架**：台词节奏比情绪强度更重要——短句、单字回应、沉默区间、省略号停顿都是节奏工具；台词内部嵌入微小生理/体态细节（声音微抖、眼神一闪、姿态转换）比独立的心理独白更能传递情绪裂缝；**潜台词承担比明文台词更重的博弈信息量**。

- **适用场景：**
  - 权力不对等的对峙：上位者逼问、审讯、谈判，弱势一方需要以逻辑或示弱争取空间；
  - 势均力敌的双方从误会走向理解的关键拐点，需要双方同步完成情绪降落；
  - 高智商角色需要在一段话内完成劝服、揭示关系、确立世界观等多项叙事功能；
  - 章纲标注有"对峙""质问""摊牌""谈判""试探"节拍的场景。

- **不可迁移边界：**
  - 连环反问型不适用于情绪失控、冲动爆发的人物——需要人物有足够的理性与信息储备才能架构逻辑闭环；若人物设定是冲动派，强行套用会失真。
  - 进—退—收型要求双方情绪处于同一量级，若一方绝对强势（权力悬殊过大、对方无退路），对称软化的节奏不成立，强行使用会让冲突解决显得廉价。
  - 以退为进型的有效性依赖于对手有明确的认知偏见或利益盲点可利用；若对手洞察力极强、无明显偏见，此策略容易被识破反噬。
  - **铁律（不得突破）**：不得为强化本能力而改写章纲事件、人物动作去向、设定真相——风格能力只影响怎么写，不改写什么。不可为制造更精彩的台词博弈而让角色说出与其掌握信息量不符的话。

### [evidence] 证据（真人摘录）

- **真人证据：**「"如果让你走呢？"郑千琴问他，"你违约了，这代价是离开唐彦。"

  "我知道。"姜危桥道，"那么我会走。"

  "哦？"

  "但是我还会再回来，再次追求他。无论您是否允许。"

  "你什么也不是。唐彦值得更好的。"

  姜危桥笑了一下："您说得对。我什么也不是，您看我的眼神像是看什么社会渣滓。唐彦的确值得更好的，只是我不能再失去他。"」——对话全程以潜台词承担博弈信息量：郑千琴每句施压，姜危桥每步表面退让实为另一种推进，"那么我会走/但是我还会再回来"的反转把被动化为主动；最后承认卑微反而成为不可辩驳的立场宣示——这是以退为进型紧张对话的教科书结构。
