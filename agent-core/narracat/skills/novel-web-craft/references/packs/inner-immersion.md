# 内心戏·视角代入（inner-immersion）

## 让读者活在角色脑子里：以内心动态取代情绪标签，实现读者与角色视角的无缝融合

### [runtime] 机制本体

- **机制注解**：内心戏的核心不是"告知情绪"，而是"同步认知过程"——让读者跟随角色一起感知、推断、压抑、爆发。真人范例中呈现四种可互换的子类型，共享同一骨架：**以具体替代抽象，以过程替代结论**。

  **子类型一：生理-感官锚定**。将情绪翻译成身体细节——气味的包围、局部特写（"连他的喉结都近在咫尺"）、生理动作序列（捏拳→吞咽→告诫自己）。读者不被告知"紧张"，而是同步体验造成紧张的每一个感官刺激。内心叫嚣与外部静止并列，"克制"本身变成叙事动力。

  **子类型二：克制型独白**。将极端情绪压进最简短的句子——"让这一切结束吧，真的太痛了"；"可他不愿退亲，也不愿娶鲁阳公主"。独白越短、越平静，对比越惨烈。不渲染，不解释，留白处由读者自行填充痛感。生理反应（额上青筋、心跳声型）作为前置铺垫，使短句落地时具有千钧之力。

  **子类型三：OS式口语独白**。将内心想法以口语化短句嵌入叙述流——"那你刚刚叭叭一大堆什么呢"、"哟呼，这是知道帮她说话了？"。句子短促、语气即时，与角色外部表现形成双线：表面平静/漠然 vs. 内心翻腾/好笑，信息密度高，常用于喜剧或人物性格快速建立。

  **子类型四：旁观者内心翻译**。以第三方视角的心理独白完成对当事人行为的深层解读——母亲望着女儿争那块肉饼，不开口，只在心里说"她要争的哪里是这个，不过是见着父亲疼别的孩子去了"。读者同时获得表层动作与深层动机，形成双重共情；旁观者的洞察不说出口，本身也构成角色塑造。

  **嵌入位置与句法**：内心独白优先嵌入动作/对话之间而非单独成段；微小生理细节（"声音微抖"）嵌入台词内部而非独立说明；极限时刻的内心问题以破折号或跳行引出，打断叙事节奏，制造意识流动感。

- **适用场景**：
  - 情感临界点（告白前夕、分别、濒死、盛怒被压制）——子类型一/二
  - 角色性格快速建立或喜剧反差场景——子类型三
  - 家庭/亲密关系中隐性冲突揭示，或角色成长节点——子类型四
  - 生死关头自然流露压抑已久的情感——子类型二，最短句，最低音量

- **不可迁移边界**：
  - 情绪已在外部动作/对话中充分呈现时，再叠加内心独白会造成重复，削弱张力——选一条线，不两条同时走满。
  - OS式口语独白依赖角色鲜明的个人腔调，若人物声音尚未建立，独白会变成作者声音而非角色声音。
  - 旁观者翻译须建立在读者已对被观察角色有足够了解的基础上，否则解读会显得生硬说教。
  - **不得为强化本维度能力而改写章纲事件、人物动作去向、设定真相——风格能力只影响怎么写、不改写什么。**

### [evidence] 证据（真人摘录）

- 真人证据：「霍希撑着椅背，低头看她。这姿势像被他半抱在怀里，四周都是他的味道，盛乔感觉自己快窒息了。她艰难地抬头，齿缝中挤出几个音节："霍希……"对上他打量的目光。她半仰着头，一动不动看着他，离得这么近，连他的喉结都近在咫尺。一个念头在脑子里疯狂叫嚣。她死死捏着拳头，吞了吞口水，拼命克制，在心里一遍又一遍告诫自己一定不要冲动！」——把"心动"拆解为气味、局部特写、生理动作序列，内部叫嚣与外部静止并列，"克制"本身成为叙事动力，读者同步体验压抑而非被告知情绪结论。
