# 温度侧写（warm-scene）

## 不直说"我在乎你"，用感官/物理/幽默的侧面渠道让温度自己渗出来

### [runtime] 机制本体

- **机制注解**：温暖名场面的共通骨架是「情感不正面出场」——作者把本可以直接说出的情感，转译成以下几条侧面渠道之一，让读者的共情由内向外生长而非被强行灌入：

  **渠道一·感官/生理替代抒情**：用心跳由重转轻、体温从布料渗过来、布料贴上身"像被人拥进怀中"这类可感知的身体信号代替"我很感动""我心里暖了"的直白陈述。生理反应有不自欺欺人的可信度，读者相信身体比相信台词更快。

  **渠道二·间接关怀/不自知旁白**：人物担心会不会分散别人精力、冤枉无辜人、让别人"做坏人"——顾虑全是替旁人着想，却一字不提自己的感情。或者用"明明什么都不在意，却让人觉得她把什么都放在心里"的对比句式，从旁观视角折射出情感，让情感以"他人的感受"形式抵达读者。

  **渠道三·物件/环境作情感锚点**：选择一个与当下关系变化形成镜像的物理细节（体温已经"渡进"斗篷的织物里；晃悠悠烛光把破房照得温馨；龙眼壳被剥开隐喻心里破了一道口子）。物件不解释自身，读者被引导自行完成比喻的闭合，情感的自发到达比被告知更有留存感。

  **渠道四·幽默着陆防溢出**：情绪高峰后立刻插入一句反差式调侃（打完架之后"你散步方式太激烈了吧"；少年脱力倒下后"不仅是小狐狸，还是个小祖宗"；苦难身世解释到一半冒出"被干掉的邪教徒首领"）。幽默不是在消解情绪，而是在稳住情绪——防止读者因过度煽情而产生抵触，同时用落差放大刚刚累积的温度。

  四条渠道可单用、可叠加；叠加时建议感官/物件先铺底，调侃或旁白收尾。共同原则：**写的是侧面，留的是正面；句子克制，情绪不克制**。

- **适用场景**：①守护/被护时刻：混乱中某人出现让另一人心跳平稳；②克制型互动：肢体接触受限但关怀必须传达（布料、食物传递体温）；③情感觉醒节点：角色从自保状态第一次为他人着想；④悲喜交加场面：沉重披露后需要情绪缓冲；⑤章节结尾需要"松一口气"的情感落点。

- **不可迁移边界**：①幽默渠道须与全章氛围匹配——在角色刚受重大打击、全章基调是沉痛的情况下强行调侃会让读者出戏；②物件锚点须在前文有铺垫或逻辑基础，临时引入陌生物件无法产生共鸣；③感官渠道须贴着感知主体的人物视角走，切换到全知叙述后立刻失效；④**不得为强化本能力而改写章纲事件、人物动作去向、设定真相——风格能力只影响怎么写、不改写写什么**；⑤幽默着陆变体与感官铺底变体的触发时机不同：前者用在情绪高峰之后（节奏需要下坡），后者用在情绪高峰之中或之前（节奏在向上爬升时）。

---

### [evidence] 证据（真人摘录）

- 真人证据：「步重华听见自己的心跳一下一下，由重转轻，由急转缓，被一股奇异而无形的力量抚平了，所有难以名状的烦躁和焦虑都消失得无影无踪。"你散步的方式太激烈了吧，队长？"」——激烈打斗的混乱在另一个人出现的瞬间归零，作者不写"她放心了"，而是用生理变化（心跳由急转缓）锁定情感，再以一句调侃打破肃静，实现感官底色与幽默着陆的双重叠加，两条渠道同时在场。
