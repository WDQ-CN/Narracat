# 情感重击（grief-strike）

## 克制胜于渲染——用行动缺位、感官破堤与反常平静，把悲伤击穿到底

### [runtime] 机制本体

- **机制注解**：情感重击的核心不是催泪，而是「不说却全说了」——让情绪在意料之外的时机、以意料之外的载体爆破，使读者主动填补空白，完成比作者代劳更深的共情。提炼出三种主要子类型及其共通骨架：

  **子类型 A — 行动代替心理（Show Nothing, Feel Everything）**：角色在情绪最强烈时不剖白，而是执行一系列机械动作（查评分、开车、停车、看了看膝盖、默默开走），视线方向的微小变化成为唯一的心理出口。悲伤落在读者身上，不在文字里。适合创伤回避、物是人非、崩溃前夕。

  **子类型 B — 克制声音载体（Micro-Detail Anchor）**：用极具体的生活细节——"有银子买花戴，没银子上山打鸟"、"嘬得还挺响，跟要咬一口似的"——承载巨大情感重量。细节的穷困/粗粝质感与情感厚度形成反差，越朴素越有力。适合离别、忆人、亲情破防。

  **子类型 C — 逻辑推演-感官破堤（Rational Collapse）**：先维持理性节奏（拼线索、做复盘、诉控诉），在确认的一瞬间切换为纯感官描写（泪打转→滚落→无数颗；呼吸停滞）。理性到感性的切换越突然，情绪冲击越强。适合真相揭露、指控对峙、谜题解答。

  三类共通骨架：**克制先行（积压）→ 触发点精准（具体细节/视线/动作）→ 情绪在读者侧完成**。节奏上，短句切割强于长句流动，情绪爆破点前必须有"留白蓄水区"（铺垫或反常镇定）。

- **适用场景**：
  - 死亡/失去之后的第一个平静时刻（而非当场崩溃）
  - 离别前最后几分钟的反常沉默
  - 角色独自面对曾经共有的场景（母校、墓碑、旧物）
  - 关系真相被摊开，控诉方以具体细节复盘积压已久的心事
  - 濒死/极限状态下，角色想要放弃而非得救的内心独白
  - 强大角色在无人处流露脆弱（私密独处场景）

- **不可迁移边界**：
  - 此机制适配克制语境；若当前章纲已定调为歇斯底里的高潮哭戏，强行压制会造成风格断层，应选情绪渲染类手法。
  - 子类型 A（行动代替心理）要求前文有足够铺垫，冷启动使用（读者对角色处境知之甚少）时情绪无法落地。
  - 子类型 C（逻辑推演-感官破堤）须让「确认」动作本身清晰可感，若谜题尚未收束即切换感官，会产生情绪失真。
  - **铁律**：不得为了强化本能力而改写章纲事件、人物动作去向、设定真相——风格能力只影响怎么写、不改写什么。悲伤必须是原始章纲中已有的情节结果，本卡只调整呈现方式。

### [evidence] 证据（真人摘录）

- 真人证据：「他查了一下那几个酒店的评分，选择了自己的午餐，然后摇着轮椅出去了。他没有去餐厅，而是去了停车场。上车关好门，把轮椅折叠起来，放到副驾驶座。然后发动引擎。他戴着骨传导耳机，跟着导航上了路，大概开了十多分钟，从大路转到了小路，又开了五分钟，停到了露天停车场。然后他愣住了。因为面前是另外一所大学，也是他的母校。从车祸后，他就没有回来过。这样骤然来到母校附近，让他有些不知所措。正是中午，校门口进出的学生很多，他们很好，青春又健康，挂着笑容，讨论着午餐去哪里吃，周末安排什么活动。他有些失神地看着那些四年前也属于自己的画面，低头看到了自己的膝盖，还有空空荡荡的小腿下面。然后他默默把车开走了。」—— 行动日志式叙事接管全部心理描写，"低头看到了膝盖，还有空空荡荡的小腿下面"这一视线动作是唯一的情绪出口，"默默把车开走了"五字关闭所有渲染，把所有悲伤转交给读者。
