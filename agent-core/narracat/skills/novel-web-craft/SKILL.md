# 网文写作功底素材库

本库的读者是组装章节任务书的压缩器，不是写手。用法：从下面的功底条目里挑出**与本章最相关的 2-3 条**，结合章纲与选中的能力 pack，把它们翻译成任务书「怎么写更顺」段里的自然语言写法要求——写手读到的必须是针对这一章的具体人话，不是通用条目转述，更不是字段名或 pack 名。

## 留人功底（取材条目）

读者在手机上读，手指随时能划走。每条说的都是「要达到什么」，怎么达到由这本书的声音决定——同一条「开篇即抓人」，毒舌吐槽的书和沉静武侠的书写出来必须不像。

1. **开篇即抓人。** 尽快让读者撞上「有意思的人 + 正在发生的事 + 一个想知道答案的问题」。
2. **钩子密度 + 章末强钩。** 关键段落落在钩子上（疑问/反常/有冲击的话），章末给最强钩、指向未来；钩子只叠加、不改写章纲写定的结尾事件。
3. **每段都推进。** 剧情、人物、悬念、情绪至少推进一样；氛围与静场只要在往前走也是推进。
4. **冲突清晰。** 谁和谁在较劲、主角眼前的阻力是什么，读者要一眼抓得住。
5. **低认知负荷。** 别让读者为读懂一句话回头重看；达成方式归这本书的声音，不是把所有书写成短句碎段。
6. **对白承担戏。** 每轮对白至少推进一件事；不同角色的句长、用词、回避与攻击方式要能区分——盖住名字也认得出谁在说。
7. **先抑后扬。** 把不公/压抑/危机做足，再释放成爽点或钩子；紧张、憋屈、痛快要真的传到读者身上。
8. **爽点按本书形态兑现。** 主角的底牌先透给读者（扮猪吃虎是给读者的承诺，不是要藏的伏笔），读者才会追着看他亮。
9. **人设记忆点。** 主角鲜明、一句话能概括的特质与反差，直接演给读者看。
10. **追读承诺。** 每章末读者心里留着至少一个具体的「还没解决/接下来会怎样」。
11. **伏笔用明钩。** 埋的时候让读者察觉「这里有戏」，制造期待不剧透；揭开时让先前的钩子「响」一声。
12. **台词要有调门。** 标点是演语气的，不是标格式的：同一句话换个标点就是另一场戏——「站住。」是陈述，「站住！」是已经扑上去了；「我不知道。」是把门关上，「我……我不知道」是心虚到卡壳。写每句台词先想它出口时是什么调门（冲、堵、虚、抢白、噎住、故意压平），再让标点把这个调门落到纸上。平铺的句号只在那句话真的该平的时候用；一整章的台词都用句号收尾，等于所有人说话都是一个表情。
13. **说话人要交代得清楚。** 并进句子里（「她问道：『……』」）、跟在话后带上动作（「『……』她说，手指还按在门框上」）、或者让上一个动作把人带出来；连着来回的对话里省掉提示语是常态，前提是读者始终知道谁在开口。把提示语从句子里剥出来单独占一行（一行只有「她说。」），孤立一两次是节拍工具，成为习惯就是口癖。
14. **句子长短跟着情绪走。** 该短就短、该展开就展开：紧张、决断、砸落点用短句；交代、铺陈、心里绕弯子的地方要敢写长，一句话把因果和情绪一并交清楚，比切成三段更好读。把整章都压成短句会让读者为读懂一句话回头重看——那是认知负荷，不是节奏感。
