感谢你向 NarraCat（下称"本项目"）贡献。为使项目维护者能够长期维护与分发本项目（包括在 AGPL-3.0 之外以其他条款授权的能力），你同意：

1. **版权许可**：你将你的贡献以永久、全球、非独占、免版税、可再许可的方式授予本项目维护者，允许其复制、修改、分发你的贡献，并可以任何许可条款（包括商业许可）再发布。
2. **专利许可**：就你的贡献中你有权许可的专利权利，你授予本项目维护者及下游接收者永久、全球、非独占、免版税的专利许可。
3. **原创性声明**：你声明贡献是你的原创作品，或你有权按本协议条款提交；若包含第三方内容，你已在贡献中明确标注其来源与许可。
4. **无义务**：维护者没有义务接受或使用你的贡献。

在 PR 中回复 CLA 机器人指定的签署语句即视为同意本协议。
