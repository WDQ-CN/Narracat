# Library Cover Preset References

These PNGs are reference assets for GitHub issue #13, "PRD: 重设计图书馆为书卡式小说库".

- `cover-01.png` through `cover-12.png` are cropped 2:3 portrait cover backgrounds.
- Each image is `512x768`.
- They intentionally contain no title text, logo, numbers, or symbols.
- The app should render the novel title on top of the cover inside a fixed title-safe zone.
- These are design reference assets. During implementation, copy or move approved production assets into the renderer asset location used by the app.
